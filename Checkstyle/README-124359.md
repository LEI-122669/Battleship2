## Technical Reflection & Limitations
Checkstyle is an effective static code analysis tool for enforcing structural formatting, syntax conventions, and naming standards across a project. By integrating the `MethodName` rule with a regex pattern, it guarantees that all newly declared methods adhere to the standard `camelCase` naming style prior to merging code into the main branch.

However, Checkstyle operates strictly at the syntax and lexical levels. It cannot evaluate the semantic clarity, readability, or context of identifier names (for example, it cannot detect whether a method name is descriptive or accurately represents its underlying behavior). Additionally, standard regex rules check single identifiers in isolation and cannot enforce system-wide naming consistency or domain-specific terminology rules.
